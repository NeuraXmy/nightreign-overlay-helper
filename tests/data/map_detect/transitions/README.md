# 地图开启／关闭时序样本

`map_open_close.npz` 来自一段 720×720、30 FPS 的实际游戏地图开启、保持、关闭视频。容器声明 236 帧，OpenCV 顺序解码得到 235 帧，以实际解码结果为准。源视频 SHA-256 为 `1f7f3fac27ec3003647b5adc5d136ce5c1e8871c170c3ba02b0309384047672b`。

为避免保存完整视频，此文件保留生产稳定性预处理后的全部 96×96 灰度样本、截图时间、原始 RGB 帧经过生产全图检查得到的布尔结果，以及 FPS 和源文件哈希。它用于验证时序门控，不替代原始图像上的全图算法回归或视频重新解码评估。

独立逐帧检查后，测试保守地将帧 72～171（2.4～5.7 秒）标注为可用于识别的完全开启窗口；标注仅用于验收，不参与识别。原全图检查从帧 62（约 2.067 秒）开始通过，关闭时直到帧 174（5.8 秒）仍通过，因此包含两类渐变误放行。

新增视频需要单独标注完全开启窗口。单次开启／关闭片段使用一个安全窗口；不同片段应分别评估。
