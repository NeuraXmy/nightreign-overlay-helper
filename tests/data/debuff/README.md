# 异常量表区域回归样本

原始数据为项目 `sandbox/debuff` 历次提供的完整游戏截图。样本仅裁剪检测区域，PNG 无损保存，不改变像素：以 1960×1100 下 `(730, 360, 450, 320)` 为参考，各图片按实际宽高比例换算边界。

文件名 `_` 前为状态编号，`None` 表示没有异常量表。测试只检查是否存在量表，不检查类型。原始场景八张为阳性、三张为阴性，包含后来补充的编号 0 和编号 3。

`None_player_controls.png` 是无量表截图 `None_2.png` 中 `(1400, 734, 450, 320)` 的额外反例，包含播放器控件，用于防止背景纹理与无关横条组合误判。

`None_scene_0.png` 至 `None_scene_9.png` 来自 2026-10-23 提供的 `sandbox/debuff/0.png` 至 `9.png`，共 10 张无量表反例，包含角色、盔甲、地形、火焰和蓝色光效。与旧数据同名的原始文件不是同一批截图；使用 `None_scene_` 前缀保留旧阳性样本。当前合计 8 张阳性、14 张阴性。

回归测试为 `tests/plugins/test_debuff_detector.py`。每张图保留原来的 17 种原图／单项增强，另测亮度（0.6、1、1.4）、对比度（0.6、1、1.4）、饱和度（0.5、1、1.5）、清晰度（5×5、σ=1 高斯模糊／原图／1.5 倍原图减 0.5 倍模糊图锐化）的全部 81 种组合。图标单独出现、横条单独出现与纯色反例在测试中合成，各量表行也单独验证。性能入口为 `benchmark/benchmark_debuff.py`，与回归测试共享增强函数 `tests/support/debuff_images.py`。
