# 队友状态录像样本

30 张真实游戏帧，按日志 `Teammate status changed` 事件随机抽样。先对录像画面居中裁剪到 16:9，再裁剪默认队友检测区域；原始 JPEG 字节保留。日志状态只用于定位帧，人工重命名标注才是 GT。

文件名 `xx_a-b.jpg` 的 `a`、`b` 分别为上下队友：`n` 无队友、`0` 未倒地、`1/2` 倒地（不区分）、`3` 三倒。包含菜单、隐藏/淡出 HUD、正常头像、紫色倒地环、金色救援环和三倒。

与 `go_down*` 的 17 张旧样本一起回归。增强参数及性能复测见 [验证记录](../../../../docs/development/testing/teammate-detection-2026-10-23.md)。
