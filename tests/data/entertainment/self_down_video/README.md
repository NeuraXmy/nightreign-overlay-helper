# 自身倒地录像样本

20 张真实游戏 JPEG 帧，从有效 `Self status changed` 日志事件中随机抽取。先居中裁剪到 16:9，再裁剪默认自身倒地检测区；尺寸为 75×76，保留原始 JPEG 字节。

文件名 `xx_x.jpg` 的末尾 `x` 是人工标注：`0` 非倒地、`1/2/3` 均为倒地，不区分阶段。日志中的状态只用于定位帧，不能代替人工 GT。包含金色救援环、紫色各阶段倒地环和容易干扰检测的蓝白特效背景。

与旧真实图、固定背景采样和连续进度合成样本共同回归；增强参数及复测方法见 [验证记录](../../../../docs/development/testing/self-down-detection-2026-10-23.md)。
