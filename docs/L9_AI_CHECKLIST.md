# L9 · AI 修改检查清单

> 在修改任何代码前，按本清单核对约束。每条规则标注了违反后果。

## 架构约束

- [ ] **依赖方向**：Core 不依赖 UI 与插件；插件之间只通过 `api.py` 建立服务契约。
  - *违反后果*：循环导入、测试困难、模块边界混乱。
- [ ] **禁止全局单例**：所有长生命周期对象由 `Application` 持有。
  - *违反后果*：测试 fixture 污染、生命周期不可控。
- [ ] **插件禁止直接导入其它插件实现**：只允许 import 提供方的 `api.py`。
  - *违反后果*：破坏封装，停用插件时产生悬空引用。

## 配置约束

- [ ] **新增配置使用 `ConfigGroup` 声明**，不要直接读写 YAML。
  - *违反后果*：缺少校验、类型不一致、UI 卡片无法绑定。
- [ ] **`ConfigItem.set()` 在 GUI 线程调用**。
  - *违反后果*：Qt 信号跨线程异常、配置写入竞争。
- [ ] **非法值应回退默认值并记录 warning**，不要抛未捕获异常。
  - *违反后果*：启动时配置损坏导致整个应用无法启动。

## 插件生命周期约束

- [ ] **`on_load()` 即使插件禁用也要能安全调用**，只绑定轻量状态。
  - *违反后果*：禁用插件的设置页崩溃。
- [ ] **运行时资源必须走 `ctx.provide / subscribe / on_cleanup`**。
  - *违反后果*：热启停泄漏服务、订阅、定时器、悬浮窗。
- [ ] **`HotkeyApi` 等设置页依赖的服务在 `on_load()` 注册**，物理监听在 `on_activate()` 启动。
  - *违反后果*：设置页构建时找不到服务。

## 截图约束

- [ ] **消费截图先 `subscribe(FrameCaptured)`，再 `acquire_stream(owner)`，清理时 `release_stream(owner)`**。
  - *违反后果*：截图定时器无法正确启停、多消费者重复截图。
- [ ] **不要在工作线程读写 Qt 对象**。
  - *违反后果*：崩溃或不可预期行为。
- [ ] **检测失败时重试，不要静默切换截图模式**。
  - *违反后果*：用户配置失效、行为不可预期。

## 热键约束

- [ ] **录制快捷键时通过 `subscribe_capture` 隔离活动热键**。
  - *违反后果*：录制过程中触发业务动作。
- [ ] **macOS 记录 pynput 实际物理键**。
  - *违反后果*：录制和运行时键位不一致。

## 悬浮窗约束

- [ ] **不要直接调用 `show()` / `hide()`，使用 `show_overlay()` / `hide_overlay()`**。
  - *违反后果*：前台门控、自身条件被绕过。
- [ ] **不要用透明度 0 代替隐藏**。
  - *违反后果*：留下不可见顶层窗口、遮挡点击。
- [ ] **子类 `should_be_visible()` 必须以 `and super().should_be_visible()` 结尾**。
  - *违反后果*：前台门控失效。
- [ ] **普通窗口模式豁免前台门控**。
  - *违反后果*：普通窗口下无法交互。

## 区域标定约束

- [ ] **保存区域使用设备像素，预览时转逻辑坐标**。
  - *违反后果*：高 DPI/多屏下坐标错位。
- [ ] **标定期间设置 `_calibrating=True` 暂停检测**。
  - *违反后果*：GUI 线程卡顿、结果覆盖。
- [ ] **设置页状态部件每次刷新/悬停重新查找 `RegionApi`**。
  - *违反后果*：region 未激活时状态页崩溃。

## UI 约束

- [ ] **设置卡片绑定 `ConfigItem`，不使用 qfluentwidgets 自带 `qconfig` 卡片**。
  - *违反后果*：配置写到工作目录 `config/config.json`，与 `settings.yaml` 不同步。
- [ ] **重置位置通过 live window 计算默认坐标并立即写入配置**。
  - *违反后果*：重置后不拖动时下次启动位置不对。
- [ ] **语言切换提示重启生效；主题切换即时应用**。
  - *违反后果*：语言未重启导致界面混用；主题未即时更新导致设置与显示不一致。

## 平台约束

- [ ] **使用平台能力前先检查 `supports_*` 属性**。
  - *违反后果*：macOS 下调用 Windows API 崩溃。
- [ ] **macOS 屏幕录制权限缺失时功能优雅降级**。
  - *违反后果*：region 冻结画面不可信导致错误区域保存。

## 代码风格约束

- [ ] **通过 `ruff check .` 和 `ruff format --check .`**。
  - *违反后果*：CI 失败。
- [ ] **模块/函数/变量 `snake_case`，类 `PascalCase`**。
- [ ] **Qt 信号/槽使用 `camelCase`**（如 `valueChanged`）。
- [ ] **使用 `get_logger(__name__)`，禁止 `print`**。

## 测试约束

- [ ] **核心逻辑变更必须补充单元测试**。
- [ ] **Qt 测试在 `QT_QPA_PLATFORM=offscreen` 下通过**。
- [ ] **提交前运行 `pytest`、`ruff check`、`ruff format --check`、`git diff --check`**。

## i18n 约束

- [ ] **当前阶段保证 `zh_CN` 词条完整**。
  - *违反后果*：其他语言回退显示键名，用户界面异常。
- [ ] **新增词条先写 `zh_CN.yaml`**，需要时再补充其它语言。
- [ ] **插件词条使用 `ctx.tr()`，核心词条使用 `tr()`**。
