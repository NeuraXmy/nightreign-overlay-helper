# 血条检测优化状态

更新：2026-10-19。

当前生产实现使用结构与材质联合检测，旧版检测器和算法选择设置已移除。完整截面优先通过两个 ONNX 模型识别可用槽体、灰段、背景及端帽，再通过有序分割和局部结构验证确定可用终点。材质路径必须提供当前帧证据；旧窄裁剪保留扫描线兼容逻辑。最近五次材质调用中至少三次坐标一致才输出，不以旧长度代替新观测。

## 优化依据与历史

早期扫描线方案对复杂背景、空血和扣上限灰段的区分存在局限。扩大截图区域的二维边框原型用于验证纵向结构的价值；随后生产流程接入材质分类和外框约束，用户仍按血条本身高度标定，由程序补充上下文。

历史实验与数据分别保存在下列资料中，应按各文档的实现日期理解，避免将历史指标当作当前能力：

- [矩形区域实验](rectangle.md)：扩大区域与二维结构原型。
- [复杂背景评估](complex-scenes.md)：粉血／黄血素材及历史方案边界。
- [材质检测说明](../../../features/hp/material-detection.md)：模型特征与生产截图。
- [材质模型回归](material-regression-2026-10-17.md)：四段录像、训练与时间块留出记录。
- [训练工具](../../../../tools/hp_material/README.md)：离线训练、数据与复现入口；模型依赖位于 `src/nightreign_overlay/plugins/hp_marker/data/`。

## 2026-10-19 验收与已接受限制

2026-10-19 发布审计记录：yellow_complex 连续回放在 0、0.05、0.25 秒采样时拒识率为 26.28%、27.21%、29.55%，冷启动聚合拒识率 37.84%，部分冷启动连续拒识 2.33 秒；pink_complex 冷启动聚合拒识率 21.24%。这些结果超过现有 warning 阈值，但仍在 failure 阈值内。拒识与误识应分别统计；用户可能看到旧标记持续一段时间。

该限制已在发布审计 A18 中标记为无需修复。本轮维护保留算法、验收阈值和统计，不通过放宽阈值消除警告。后续算法改善需要新的独立录像，尤其是带灰段、复杂特效、不同 HUD 比例与 HDR 的场景，并保留录像级隔离、冷启动、最长拒识和逐项误报记录。
