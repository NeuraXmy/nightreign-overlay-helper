这是 Nightreign Overlay Helper 重制版的首次正式发布。

本次对项目进行了大幅重写，重新实现了应用架构、插件系统、设置界面、悬浮窗和识别流程，并整合地图信息、缩圈计时、雨中冒险计时、绝招倒计时及 Steam 联机队友与延迟显示等功能。

- 修复受邀好友因 Steam 历史记录缺失或过期而无法显示的问题。
- 更新多语言 FAQ，补充共享计时悬浮窗的设置入口和截图方式排查建议。
- 修复发布附件处理，提供独立的 Windows 程序包和对应源码包。

下载 `nightreign-overlay-helper-v1.0.1-windows-x64.zip`，解压后运行文件夹内的 `nightreign-overlay-helper.exe`，请保留完整文件夹。

`v1.0.1-sources.zip` 为本次构建的对应源码及依赖源码包，运行程序无需下载。

This is the first stable release of the rewritten Nightreign Overlay Helper. The application architecture, plugin system, settings, overlays, and recognition workflows have been extensively rewritten.

Download the Windows ZIP to run the application. Keep the entire extracted folder. The separate sources ZIP contains the corresponding project and dependency source code.
