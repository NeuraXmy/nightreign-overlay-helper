v1.0.3 更新日志

- QoL
    - 标定区域支持自动计算，无需再手动标定
    - 优化截图方式，修复旧版“仅前台”挤压游戏窗口的问题
    - 检查更新支持跳过版本，添加 CNB 源
- Steam 联机功能
    - 能够队友展示游玩时间，以及点击进入 Steam 个人资料
    - 添加通过临时屏蔽展示队友 Steam 名称的功能
    - 添加赛后点赞功能，游戏结束后弹出窗口可进行点赞留言
- 计时功能
    - 添加废弃物之王遗物词条对异常量表检测的计时
    - 绝招倒计时功能添加对送葬者额外大招的计时
- 地图识别
    - 显示商人村的标签，用于隐藏地图
- 娱乐
    - 添加队友倒地自动播放音频功能
    - 添加绝招期间自动播放音频功能

v1.0.3 Changelog

- QoL
    - Calibration regions can now be calculated automatically, removing the need for manual calibration.
    - Improved screen capture and fixed an issue where the previous “Foreground only” mode displaced the game window.
    - Update checks now support skipping versions, with CNB added as an update source.
- Steam Multiplayer Features
    - View teammates’ playtime and click to open their Steam profiles.
    - Reveal teammates’ Steam names through temporary blocking.
    - Added post-game commendations: a popup after the game lets you leave a positive comment.
- Timers
    - Added a status ailment buildup timer for the relic effect on The Night of Dregs.
    - Added countdown support for Undertaker’s additional Ultimate Art activation.
- Map Detection
    - Added merchant village labels for Hidding maps.
- Entertainment
    - Added automatic audio playback when a teammate is downed.
    - Added automatic audio playback during Ultimate Arts.
