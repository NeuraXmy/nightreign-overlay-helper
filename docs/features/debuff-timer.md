# 异常量表计时

`debuff_timer` 为“出现异常量表时提升攻击力，之后每 20 秒判定并叠层”的词条显示倒计时与层数。插件默认关闭，需要在功能页启用。使用共享截图、区域标定、快捷键和 HUD 服务，不依赖地图识别插件启用。

## 检测与计时

- 等待首次触发：订阅共享截图流，使用通用设置中的检测频率。检测到任意异常量表后记为 Lv.1，开始 20 秒倒计时。
- 手动快捷键：可分别配置开启、关闭，默认未绑定。手动开启会从 Lv.1 开始新的 20 秒周期（正在计时时重新开始）；手动关闭会清零并隐藏计时条，恢复自动检测等待首次触发。
- 计时阶段：释放本插件的连续截图请求，只在倒计时结束时请求新截图并检测一次。其他插件发布的中途截图不会改变计时和层数。
- 节点存在量表：增加一级，最多 Lv.10，再开始 20 秒倒计时；Lv.10 时继续判定以维持层数。
- 节点没有量表：清零、隐藏计时条，重新按通用频率等待首次出现。
- 周期内消失、重现、切换异常类型或打开背包均不影响计时。节点时背包遮挡量表按没有量表处理。
- 截图失败、区域不可用或区域超出截图范围不作为无量表；可用后重试节点检测。截图失败时按一秒间隔重试，不重复堆积异步请求。
- 停用、退出或重置设置清空层数和计时。不能从截图还原启用前已经获得的层数。

HUD 文本为 `异常量表提升攻击力 Lv.3 下次检测 15.2s`，进度条使用巧克力色 `#B87945`。位置、缩放与隐藏文字由共享 HUD 设置管理；等待触发时计时条隐藏。

## 音频提醒

音频设置提供“每轮倒计时结束提醒”定长音频选项，默认关闭，支持选择音频、音量、试听和提前秒数。提前 0 秒时在每轮 20 秒结束时播放；提前 3 秒时在剩余 3 秒播放；提前时间达到或超过 20 秒时在该轮开始时播放。自动触发和手动开启均适用，Lv.10 时继续每轮提醒。

每轮只触发一次，节点截图失败重试不会重复播放。即使节点检测后清零，已触发的结束提醒仍可播放完；手动关闭、重开、停用或重置会停止本插件的播放。定长音频沿用全局互斥规则，与循环音频独立。

## 标定与识别

自动区域在 1960×1100 游戏画面下对应 `(730, 360, 450, 320)`，换算为项目 2560×1440 参考坐标后是 `(953, 471, 588, 419)`。功能区域手动标定优先于自动区域，详见[自动识别区域](automatic-regions.md)。框选时需覆盖所有异常图标及其量表可能出现的完整范围，包含上下排列的多行量表；不应只截一个图标或进度条。

检测器将区域缩小为 225×160，使用从实际量表截图中提取的七类图标模板（编号 0 包含普通、火焰两份场景参考）进行多尺度灰度匹配、图标内部细节验证，以及右侧水平量表结构验证。只判断是否存在至少一组图标和量表，不输出类型、数量或填充进度。图标参考每边内裁 3 像素，去除外围背景；量表位置仍按原外框计算。优先匹配常见尺度，找到任意一组有效图标和量表后立即返回。模板仅在激活时加载。裁剪来源与坐标见 `plugins/debuff_timer/icons/README.md`；不使用地图信息页的图标。

当前固定截图与亮度、对比度、饱和度、模糊、锐化、偏移、缩放增强由回归测试覆盖；它们不代替真实对局、动画、HDR 和其他 HUD 布局的验收。

## 实现与测试

- `plugins/debuff_timer/plugin.py`：截图订阅、20 秒节点、层数、HUD 和标定生命周期。
- `plugins/debuff_timer/detector.py`：量表存在检测。
- `tests/plugins/test_debuff_timer.py`：固定节点、上限、清零、异步回调失效与标定设置。
- `tests/plugins/test_debuff_detector.py`：无损区域截图、图像增强、只有图标或横条的反例。
- `tests/fixtures/debuff/`：从原始完整画面按参考区域裁剪的无损样本。
