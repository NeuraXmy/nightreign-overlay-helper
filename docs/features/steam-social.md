# 队友时长、主页与赛后点赞

## 联机状态

- **显示游戏时长（无需 API Key）**：默认开启，可在「联机状态」页关闭。显示队友的黑夜君临累计游玩时间，并非本局用时。关闭后移除时长列并停止查询。
- 数据来自匿名访问的 Steam 公开主页近期游戏卡片，只读取黑夜君临 AppID `2622380`。隐私限制、页面未展示本游戏、网络错误或无法解析时显示「时长不可用」，不显示成零小时。Steam 展示的数据可能经过取整。
- 点击名字通过 `steam://url/SteamIDPage/<SteamID64>` 打开 Steam 客户端内的对应主页。刷新复用同一 SteamID 的控件；拖动、右键菜单及已经离队的旧点击不会误开其他人的主页。
- 查询最多并发两项，有总超时、页面大小上限和有界缓存；成功缓存十分钟，不可用结果五分钟后可重试。无需填写密钥、导入 Cookie 或保持网页登录。

## 独立「赛后点赞」页面

左侧新增「赛后点赞」，页面顶部有功能开关。点赞使用独立窗口，不与联机延迟窗口共用位置或大小。

1. 开启联机状态和缩圈计时，识别到 DAY1 后开始记录本局队友。
2. 根据连续、有效的 Steam 名单确认某人离队超过三秒后，弹出该队友的入口。留在大厅的好友不阻止另一人的提示；名单短暂消失、辅助进程失败或长时间无新数据不算连续离队证据。
3. **离队是对局结束的近似依据**，中途掉线也可能触发。没有 DAY1、或结束后仍组队时，可在本页点击「显示队友」手动打开本次运行内的最近/当前队友。
4. 每位队友出现后分别计时，默认 **120 秒**，可设置为 **10–600 秒**。刷新不会延长倒计时；开始下一局或关闭功能会清除旧提示，也可点击 × 立即关闭。
5. **名字只打开主页，👍 才发送留言。** 在本页编辑并保存 1–500 字的留言；不会自动发送。切换账号、页面未登录、主页关闭留言等情况下，显示失败状态并可手动打开主页查看。

DAY1 按连续识别去重：两次识别之间不足 10 秒时只延长去重窗口，不重建名单；间隔达到 10 秒后的 DAY1 可开始新局，不再限制开局后两分钟。明确结束记录后可立即开始新局。快速重开、再次匹配同一个人或邀请的好友持续留房，都重新按本局名单处理；不会清除七天留言间隔记录。

## 留言与防重复

- 点赞是向对方 Steam 主页发送已保存的文字，使用短时原生辅助进程和 [Steam HTML Surface](https://partner.steamgames.com/doc/api/ISteamHTMLSurface)。网页会话留在 Steam 自己的浏览器内，不导出登录数据。
- 每次请求固定本局 Steam 登录账号与目标账号，网页操作再次验证账号、目标主页及导航标识；切换账号后旧队友入口不能发送。
- **发送前先持久化七天占位记录**。成功、结果不明、发送时断网或程序闪退都保留防重复限制，不会在启动后重放留言。仅 Steam 明确拒绝或发送前置条件失效时，允许一分钟后的再次手动尝试。
- 历史按「本账号–目标账号」隔离，文件锁阻止多个辅助进程同时发送；记录损坏或无法写入时不发送。
- Windows 默认将记录保存到 `%LOCALAPPDATA%/NightreignOverlayHelper/identity/commendations/`；重置设置不会清空该记录。自定义 `NROH_DATA_DIR` 的隔离运行使用该目录下的 `commendations/`。
- 留言要求 Steam 与游戏仍在运行。辅助进程只在用户点击时启动，游戏退出/账号变化会中止，任务结束释放 Steam API。
- 启用 [显示玩家真实Steam名](steam-recovery.md) 后，存在该队友的待恢复事务时显示「等待解除屏蔽」并停用留言按钮；恢复确认后可点击。名字仍可打开主页，原生任务按账号和目标互斥，避免留言与恢复同时操作。

## 代码与验证入口

- `plugins/p2p_latency/api.py` 发布每个有效名单快照，包含未变化的名单；状态和程序清理产生的空名单不冒充真实快照。
- `plugins/p2p_latency/playtime.py` / `public_playtime.py`：匿名时长查询。
- `ui/components/steam_profile.py`：主页点击和拖动分离。
- `plugins/commendation/`：独立页面、窗口、对局名单和限时状态。
- `native/NightreignP2PHelper/Commendation*.cs` / `SteamCommentSession.cs`：账号检查、原子防重复记录、单次留言。
- Python 回归：`tests/plugins/test_keyless_playtime.py`、`test_steam_profile_actions.py`、`test_commendation.py`、`test_p2p_latency.py`。
- 原生回归：`dotnet run --project native/NightreignP2PHelper.Tests -c Release`。

离线测试不等同于 Steam 主页真实跳转、留言成功或连续实机对局验收。
