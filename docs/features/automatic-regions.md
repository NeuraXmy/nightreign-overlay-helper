# 自动识别区域

没有手动标定时，助手根据游戏画面区域自动计算各功能的识别范围。游戏画面区域默认取 Windows 自动检测到的游戏窗口客户区，也可以在通用设置的“截图设置”中手动标定。

## 使用规则

- **功能区域的手动标定优先**：某项功能有手动标定时使用该区域；没有手动标定时才使用自动计算区域。设置页状态旁的清除按钮只清除对应功能区域，其他区域不受影响。
- **自动计算依赖游戏画面区域**：默认由 Windows 自动判断实际游戏窗口客户区。也可以在通用设置的“截图设置”最后一项标定游戏画面区域，供所有自动区域计算使用；手动标定的游戏画面区域优先于 Windows 自动判断。清除它后恢复自动判断。
- **自动区域仅支持 16:9 游戏画面**：手动框选的游戏画面会按中心裁剪成精确 16:9；选区宽高比与 16:9 的相对偏差不得超过 5%，否则标定失败并清除游戏画面标定。Windows 自动获取的客户区也只在 16:9 时参与自动计算。非 16:9、游戏未启动、最小化或客户区小于 640 × 360 时，不猜测自动坐标。
- 自动坐标使用物理像素，跟随游戏窗口移动和尺寸变化，支持副屏负坐标；不会再次乘 Windows 缩放比例。
- 手动标定仍保存为原来的绝对物理像素坐标，不自动移动或覆盖；用户移动窗口、改变分辨率或使用特殊 HUD 布局后，可以重新标定。
- 设置页的眼睛图标保留预览，状态显示自动区域、已标定或等待自动区域。清除游戏画面标定后，Windows 自动判断重新生效；清除功能区域标定后，该项恢复按当前游戏画面区域计算。
- 自动区域只在运行时计算，不写入配置。因此下次启动不会把上次自动坐标误认为手动标定。

标定按钮和标定快捷键始终可用；取消框选不会丢失原有区域。重新识别地图、切换地图结果、手动计时及绝招快捷键继续使用原有注册与前台/显示条件，不因自动区域而禁用。自动区域不会替用户设置未绑定的快捷键。

## 默认布局

坐标以默认 HUD 的 2560 × 1440 游戏客户区左上角为原点，格式为 `(x, y, 宽, 高)`，其他 16:9 尺寸按比例换算；地图保持正方形。

| 功能 | 参考区域 |
| --- | --- |
| DAY 图标 | `(1112, 733, 342, 95)` |
| 雨中血条颜色 | `(240, 58, 20, 8)` |
| 地图 | `(1454, 228, 990, 990)` |
| 血量标记基准 | `(223, 56, 112, 12)` |
| 绝招图标 | `(1206, 1260, 143, 140)` |
| 队友状态区域 | `(65, 216, 457, 249)` |

这是默认 HUD 坐标适配，不会自动学习自定义布局，也不保证所有语言、HUD 调整和特殊画面都能识别。颜色参考、识别阈值与游戏语言仍由各功能配置管理。

## 实现与验证

- `CaptureApi.game_client_rect()` 优先返回手动标定的游戏画面，否则返回当前可用的 Windows 游戏客户区；不启动截图流。macOS 等平台未设置手动区域时返回不可用。
- Windows 通过窗口状态和进程路径确认 `nightreign.exe`，只查询系统窗口与有限进程信息，不读取游戏内存、不调用 Steam。
- `RegionApi.region()` 统一执行手动优先规则，所有现有检测插件和快捷键都消费同一入口。
- `tests/plugins/test_automatic_regions.py` 覆盖比例、偏移、配置持久化、手动优先、取消/清除标定、地图重新识别和五类标定快捷键。
- `tests/plugins/test_game_client_geometry.py` 与已有多屏测试覆盖游戏窗口过滤、重启/最小化、当前几何查询、DPI 上下文恢复及三种截图模式。

离线回归与只读窗口尺寸检查不能替代真实对局中的识别成功率和物理快捷键验收。
