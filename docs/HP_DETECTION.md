# 血条长度识别

血量阈值标记根据完整的可用血条长度绘制低血量、高血量和满血参考线。可用长度包含保有血、短暂掉血、可恢复血与空血，排除灰色扣血上限区域和血条外的场景。

## 设置与输入

在“血量阈值标记”的“标定与阈值标记”分组中，通过“血条识别算法”选择：

- **新版**（默认）：仅根据水平中线的相对亮度和边界结构识别，不匹配固定 RGB 或 HSV 颜色。
- **旧版**：检测中线亮度峰，通过历史聚类和平滑稳定输出。

已有配置未保存算法选项时使用新版，重置设置也恢复新版。切换立即生效；切换前尚未完成的结果会被丢弃，历史检测状态在后续任务中重置。

标定时选区左侧紧贴血条起点，确保选区的水平中线穿过血条内部。上下边缘可稍微超出血条，但选区中线不能落到血条外。两种算法均忽略框选宽度，从左侧向右扩展至“检测区域宽高比 × 选区高度”（默认 125 倍），截图边缘处按可用范围裁剪。新版需要血条右侧上下文，不会仅因图片结束就认定那里是血条终点。检测长度使用截图的物理像素，显示时由悬浮窗换算 DPI。

两种算法拒识时均保留已显示的标记，等待之后的有效结果；首次识别成功之前不显示标记。低／高血量标记比例位于高级选项。三条标记为顶部平、底部尖的楔形，可调整颜色与大小。“标记大小”位于基础分组，范围 50%–300%，默认 100%，同时缩放宽高；高级选项中的顶部宽度与高度以 Qt 逻辑像素为基准，缩放后由 Qt 随屏幕 DPI 绘制，最小为 1 个逻辑像素。血条位置与长度仍从截图物理像素换算，避免高 DPI 屏幕上标记偏小。高级设置中标有“旧版”的标准高度、亮度峰和历史样本参数仅影响旧版；绘制参数与检测区域宽高比对两种算法均有效。

## 实现

- [`config.py`](../src/nightreign_overlay/plugins/hp_marker/config.py)：算法选项及传给工作线程的配置快照。
- [`detector.py`](../src/nightreign_overlay/plugins/hp_marker/detector.py)：算法分派与旧版检测、历史平滑。
- [`structural.py`](../src/nightreign_overlay/plugins/hp_marker/structural.py)：新版结构检测。
- [`plugin.py`](../src/nightreign_overlay/plugins/hp_marker/plugin.py)：截图裁剪、串行后台任务及悬浮窗更新。

新版只提取裁剪图的中间一行 RGB 像素，不读取上下框线，也不依赖裁剪高度估计边界特征大小。先根据左端帽的亮度衰减估计局部特征尺度，再用相对亮度归一化、平稳区间、端帽的上升／下降形状和相邻分界距离判断终点。短灰色扣血上限段需有后续端帽证据；无法区分内部可恢复血分界与上限分界时允许拒识。

红色和紫红色使用同一套判断，没有固定色相或 RGB 目标。部分边界会比较前后三通道最大值与最小值之差的相对变化，帮助区分有色血量、较中性的上限段及复杂背景；这不是固定调色板匹配。完全去色后若这部分证据丢失，允许拒识。

平滑在抽取中线之后仅沿水平方向进行，在原始中线及两个轻微平滑尺度下分别判断，至少两个尺度有输出且所有有效输出接近时才接受。端帽不足、过曝裁切、边界证据不足或尺度结果不一致时返回 `None`。新版为无状态单帧算法，使用已有 NumPy 和 Pillow 依赖，无需模型或额外运行库。

## 回归测试与限制

[`tests/data/hp_detect/`](../tests/data/hp_detect/) 保留 12 张输入截图及 `gt/` 下的同名裁剪，GT 宽度为有效血条长度，其中 `11.jpg` 和 `12.jpg` 对应的 GT 使用 PNG 格式。GT 仅用于测试判定，不传入算法。容差为原始分辨率下 ±3 像素，缩放测试按实际宽度比例调整。

旧版对每张截图使用独立检测器连续输入 20 帧，表中为最终结果。新版单帧输出。旧版 7 张正确、2 张误判、3 张拒识；新版 9 张正确、0 张误判、3 张拒识。`6.jpg` 输入恰好结束于 GT 边界，缺少右侧上下文，因此拒识。静态重复输入不等同于真实视频验证；这 12 张截图也是算法调参样本，不能作为独立泛化准确率。

必要回归覆盖两种算法的原图结果、新版的亮度／对比度／饱和度变化、强模糊／锐化／Gamma 与缩放、无边界输入拒识、中线以外像素变化不影响结果，以及设置切换、过期任务丢弃和拒识保持显示：

```bash
QT_QPA_PLATFORM=offscreen python -m pytest -p no:capture \
  tests/plugins/test_hp_marker.py tests/plugins/test_hp_detection_accuracy.py \
  tests/legacy/test_hp_marker_legacy_parity.py -q
```

中线方案允许上下标定边缘略有偏差，但不能补偿中线落到血条外。回归测试会替换中线之外的全部像素、上下对称增加背景，以及仅保留中线，验证结果保持一致；这不代表任意非对称上下扩框都安全，因为那可能移动取样中线。

颜色与图像增强的同集检查使用每张图 32 个确定性版本：亮度 0.35／0.6／1.4／1.8／2.5，饱和度 0／0.2／0.5／2／4，对比度 0.25／0.5／1.5／2.5，锐度 0／3／6，高斯模糊半径 0.5／1／2／4，Gamma 0.5／0.75／1.5／2.2，缩放 0.5／0.75／1.25／1.5／2，以及两组组合增强。亮组合为亮度 1.6、饱和度 0.3、对比度 1.8、模糊半径 0.8；暗组合为亮度 0.4、饱和度 2.5、锐度 4。Gamma 使用 `255 × (输入 / 255)^gamma`，缩放使用 LANCZOS，误差容差随实际宽度比例缩放。

384 个增强版本中，中线新版 215 次正确、169 次拒识、0 次误判；有效输出准确率 100%，覆盖率约 56%。这些增强来自同一组调参截图，不能作为独立泛化准确率或真实 HDR 验收。必要回归保留了强亮度、强对比度、低饱和度、强锐化、强模糊与 Gamma 等代表性情况。多尺度一致仍不能保证所有实际场景都能正确拒识；真实 HDR、不同截图链路及连续血条变化需要实机验证。
