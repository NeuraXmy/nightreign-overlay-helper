# 懸浮窗測試

這是一個**不依賴遊戲**的示範功能，用來確認懸浮窗相關的基礎能力在目前系統上運作正常。

## 你會看到什麼

啟用後，螢幕頂部中央會出現一個小面板，顯示：

- 標題和目前時間
- 一個循環倒數和進度條
- 遊戲視窗是否位於前景，以及目前的懸浮窗顯示方式

## 可以測試的內容

| 操作 | 預期結果 |
| --- | --- |
| 按住左鍵拖曳面板 | 面板跟隨移動，重新啟動程式後位置保持不變 |
| 右鍵點擊面板 | 彈出選單：重設位置 / 開啟滑鼠穿透 / 開啟主介面 |
| 調整「不透明度」「縮放」 | 面板即時變化 |
| 開啟「滑鼠穿透」 | 滑鼠點擊會穿過面板；需要在設定頁中關閉 |
| 關閉「顯示背景面板」 | 只剩文字和進度條，可用於檢查透明背景是否正常 |
| 在「設定 → 懸浮窗顯示方式」中切換 | 面板在透明懸浮窗與一般視窗之間切換 |

## 常見問題

- **面板背景是黑色/白色而不是透明**：目前系統不支援透明懸浮窗，請在「設定 → 懸浮窗顯示方式」中選擇「一般視窗」。
- **開啟「僅在遊戲位於前景時顯示」後面板消失**：遊戲未執行或不在前景時這是正常現象。macOS 上無法偵測遊戲視窗，此選項不會生效。
