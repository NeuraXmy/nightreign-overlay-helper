# オーバーレイテスト

**ゲームを必要としない**デモ機能です。オーバーレイの基本機能がお使いの環境で正しく動作するかを確認できます。

## 表示内容

有効にすると、画面上部中央に小さなパネルが表示されます。

- タイトルと現在時刻
- 繰り返すカウントダウンとプログレスバー
- ゲームウィンドウが前面かどうか、および現在のオーバーレイ表示方式

## 試せること

| 操作 | 期待される結果 |
| --- | --- |
| 左ボタンでパネルをドラッグ | パネルが移動し、再起動後も位置が保持される |
| パネルを右クリック | メニュー：位置をリセット / クリック透過を有効にする / メインウィンドウを開く |
| 「不透明度」「拡大率」を変更 | パネルが即座に変化する |
| 「クリック透過」を有効にする | クリックがパネルを通過する（設定タブで解除） |
| 「背景パネルを表示」をオフにする | 文字とプログレスバーのみになり、透過の確認に使える |
| 「設定 → オーバーレイ表示方式」を切り替える | 透過オーバーレイと通常ウィンドウが切り替わる |

## トラブルシューティング

- **背景が透明ではなく黒／白になる**：この環境は透過オーバーレイに対応していません。「設定 → オーバーレイ表示方式」で「通常ウィンドウ」を選択してください。
- **「ゲームが前面のときのみ表示」を有効にするとパネルが消える**：ゲームが起動していない、または前面にない場合は正常な動作です。macOS ではゲームウィンドウを検出できないため、この設定は効果がありません。
