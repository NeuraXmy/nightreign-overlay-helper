# 悬浮窗测试

这是一个**不依赖游戏**的演示功能，用来确认悬浮窗相关的基础能力在当前系统上工作正常。

## 你会看到什么

启用后，屏幕顶部中央会出现一个小面板，显示：

- 标题和当前时间
- 一个循环倒计时和进度条
- 游戏窗口是否位于前台，以及当前的悬浮窗显示方式

## 可以测试的内容

| 操作 | 预期结果 |
| --- | --- |
| 按住左键拖动面板 | 面板跟随移动，重启程序后位置保持不变 |
| 右键面板 | 弹出菜单：重置位置 / 开启鼠标穿透 / 打开主界面 |
| 调整「不透明度」「缩放」 | 面板实时变化 |
| 开启「鼠标穿透」 | 鼠标点击会穿过面板；需要在设置页中关闭 |
| 关闭「显示背景面板」 | 只剩文字和进度条，可用于检查透明背景是否正常 |
| 在「设置 → 悬浮窗显示方式」中切换 | 面板在透明悬浮窗与普通窗口之间切换 |

## 常见问题

- **面板背景是黑色/白色而不是透明**：当前系统不支持透明悬浮窗，请在「设置 → 悬浮窗显示方式」中选择「普通窗口」。
- **开启了「仅在游戏位于前台时显示」后面板消失**：游戏未运行或不在前台时这是正常现象。macOS 上无法检测游戏窗口，此选项不会生效。
