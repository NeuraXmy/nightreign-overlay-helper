# 功能介紹

開啟本頁頂部的開關，並啟用「連線狀態」和「縮圈計時」，即可在隊友離隊後自動顯示按讚視窗。

1. 偵測到 DAY1 後記錄本局隊友。
2. 隊友離隊後分別顯示，中途斷線也會觸發。仍在大廳的好友不影響其他隊友的提示。
3. 點擊名字在 Steam 內開啟個人檔案；點擊右側 👍 傳送本頁儲存的留言。
4. 預設顯示 120 秒，可設為 10–600 秒，也可以點 × 立即關閉。每人分別計時，重新整理不會延長時間。

如果結束後隊友仍在隊伍裡，或未辨識到 DAY1，請點擊設定中的「顯示隊友」手動開啟。

向同一玩家留言的間隔為七天。傳送時請保持 Steam 和遊戲執行；若結果不確定，請點擊名字到個人檔案核對。對方未開放留言時，可直接查看其個人檔案。

執行狀態會顯示在設定頁底部。按讚視窗的位置、透明度與大小可獨立調整。
