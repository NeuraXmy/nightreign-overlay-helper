# 機能紹介

このページ上部のスイッチをオンにし、「マルチプレイ状況」と「収縮タイマー」を有効にすると、味方が退出したときに称賛ウィンドウを自動表示します。

1. DAY1 を検出すると、その試合の味方を記録します。
2. 味方が退出するたびに個別に表示します。試合途中の切断でも表示されます。ロビーに残っているフレンドがいても、ほかの味方への表示には影響しません。
3. 名前をクリックすると Steam 内でプロフィールを開きます。右側の 👍 をクリックすると、このページで保存したコメントを投稿します。
4. 初期設定では 120 秒間表示します。10～600 秒に変更でき、× をクリックすればすぐに閉じられます。表示時間はプレイヤーごとに計測し、更新されても延長しません。

試合後も味方がパーティーに残っている場合や DAY1 を検出できなかった場合は、設定の「味方を表示」をクリックして手動で開いてください。

同じプレイヤーへのコメント投稿には 7 日間の間隔を設けています。投稿時は Steam とゲームを起動したままにしてください。結果が不確かな場合は、名前をクリックしてプロフィールで確認してください。相手がコメントを受け付けていない場合も、プロフィールを直接確認できます。

動作状態は設定ページの下部に表示します。称賛ウィンドウの位置、不透明度、サイズは個別に調整できます。
