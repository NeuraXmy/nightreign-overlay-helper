# 赛后点赞

打开本页顶部开关即可启用独立点赞窗口。自动提示同时需要开启「联机状态」和「缩圈计时」。

1. 检测到 DAY1 后记录本局队友。
2. 某位队友确认离队后显示该玩家，不用等待留在大厅的好友离开。中途掉线也可能触发，暂时缺少新名单不会直接判定离队。
3. 点击名字在 Steam 内打开主页；点击右侧 👍 才发送本页保存的留言。
4. 默认显示 120 秒，可设置为 10–600 秒，也可以点 × 立即关闭。每人分别计时，刷新不会延长时间。

如果结束后队友仍在队里，或没有识别到 DAY1，点击设置中的「显示队友」手动打开。当前运行中没有队友记录时不会显示空窗口。

留言成功后七天内不重复发送。断网或闪退导致结果不确定时也保留间隔，请先到主页核对。Steam 切换账号、关闭留言或游戏已经退出时可能无法发送。文字留言仅在点击时发送，不需要填写 API Key 或提供 Cookie。

重置本页设置不会清除防重复记录。联机延迟和点赞窗口的位置、透明度与大小分别设置。
