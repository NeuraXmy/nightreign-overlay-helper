# 标定教程

### 正常情况：不需要手动标定

正常情况下，**无需手动标定**，你可以跳过教程中的标定步骤。

悬浮助手会在进入全屏游戏后，自动认为**屏幕中央 16:9 的区域**为游戏画面，并自动计算各个区域大小。

此时各个功能的标定选项卡会显示绿色字体的“自动（16：9）”，鼠标移动到眼睛图标上，能够看到其自动计算的区域。


### 需要手动标定游戏画面的情况

如果：
- 你游戏并不是无边框窗口化的全屏模式
- 需要检测的不是游戏窗口（例如 PS 串流画面 / 游戏录播）

则需要使用通用“设置”页面的 “截图设置” -> “游戏画面区域” 框选包含游戏画面的区域（不包括黑边）

![游戏画面](1.jpg)

框选过后显示绿色“已标定”说明成功。


### 需要手动标定各个功能区域的情况

如果：
- 前面的步骤设置后无效，并且查看区域有明显错误（比如说地图标定的区域和游戏里的地图对不上）
- 游戏画面不是 16:9

则需要在各个功能的设置页面中手动标定。

请前往各功能的教程，点击展开折叠内容，查看手动标定步骤。


### 注意事项

若识别功能无效，除了调整标定以外，也可尝试更换 “截图设置” -> “截图方式”

其他问题请查看 “常见问题” 页面
