# 範囲指定チュートリアル

### 通常は手動で範囲を指定する必要はありません

通常、**手動で範囲を指定する必要はありません**。各チュートリアルの範囲指定手順は省略できます。

全画面ゲームに入ると、オーバーレイヘルパーは**画面中央の16:9の範囲**をゲーム画面として扱い、各範囲の大きさを自動計算します。

各機能の範囲指定タブには、緑色で「自動（16:9）」と表示されます。目のアイコンにカーソルを合わせると、自動計算された範囲を確認できます。

### ゲーム画面を手動で指定する場合

次のいずれかに該当する場合：

- ゲームがボーダーレス全画面モードではない。
- PSのストリーミング画面やゲーム録画画面など、ゲーム以外のウィンドウを検出したい。

一般の「設定」ページで「キャプチャ設定」→「ゲーム画面範囲」を開き、黒帯を除いてゲーム画面を含む範囲を選択してください。

![ゲーム画面](1.jpg)

緑色の「指定済み」と表示されれば完了です。

### 各機能の範囲を手動で指定する場合

次のいずれかに該当する場合：

- 前の手順を設定しても動作せず、プレビュー範囲が明らかにずれている（例：指定したマップ範囲がゲーム内マップと一致しない）。
- ゲーム画面が16:9ではない。

各機能の設定ページで手動指定する必要があります。

各機能のチュートリアルを開き、折りたたまれた項目を展開して手動指定の手順を確認してください。

### 注意事項

認識が機能しない場合は、範囲の調整に加えて、「キャプチャ設定」→「キャプチャ方式」を変更してみてください。

その他の問題については「よくある質問」ページを参照してください。
