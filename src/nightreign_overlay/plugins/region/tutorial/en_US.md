# Calibration Tutorial

### Normally, manual calibration is not needed

Under normal circumstances, **manual calibration is not needed**. You can skip the calibration steps in the tutorials.

After you enter a full-screen game, the overlay helper treats the **centered 16:9 area of the screen** as the game image and automatically calculates the size of each region.

Each feature's calibration tab will show "Auto (16:9)" in green. Hover over the eye icon to preview the automatically calculated region.

### When to calibrate the game image manually

If:

- Your game is not running in borderless fullscreen mode.
- You need to detect a window other than the game (such as a PlayStation stream or a game recording).

Go to the general "Settings" page → "Capture settings" → "Game area" and select the area containing the game image, excluding black borders.

![Game image](1.jpg)

A green "Calibrated" status confirms success.

### When to calibrate individual feature regions manually

If:

- The previous setup does not work and the region preview is clearly incorrect (for example, the calibrated map region does not line up with the in-game map).
- The game image is not 16:9.

You need to calibrate the regions manually on each feature's settings page.

Open the relevant feature's tutorial and expand the collapsible section to view its manual calibration steps.

### Notes

If recognition does not work, in addition to adjusting calibration, try changing "Capture settings" → "Capture method".

For other issues, see the "FAQ" page.
