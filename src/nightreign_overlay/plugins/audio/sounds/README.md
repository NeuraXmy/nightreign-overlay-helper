# 内置默认语音

本目录包含 10 条默认中文语音，总计 253,320 字节，随源码和 Windows 运行 ZIP 分发。
播放内置语音无需网络或 API Key。

| 资源文件 | 语音内容 | 默认触发时间 |
| --- | --- | --- |
| `day1.mp3` | 第一天开始 | DAY I 开始 |
| `day2.mp3` | 第二天开始 | DAY II 开始 |
| `day3.mp3` | 第三天开始 | DAY III 开始 |
| `first_circle.mp3` | 三十秒后开始第一次缩圈 | 第一次缩圈前 30 秒 |
| `second_circle.mp3` | 三十秒后开始第二次缩圈 | 第二次缩圈前 30 秒 |
| `rain_start.mp3` | 雨中冒险开始 | 雨中冒险开始 |
| `rain_warning.mp3` | 雨中冒险还剩30秒 | 雨中冒险倒计时结束前 30 秒 |
| `rain_end.mp3` | 雨中冒险结束 | 倒计时到期或提前离开雨区；每次计时仅播一次 |
| `art_start.mp3` | 绝招效果已生效 | 绝招效果开始生效 |
| `art_end.mp3` | 绝招效果还剩三秒 | 绝招效果结束前 3 秒 |

每项默认关闭，可按需开启、更换本地文件、调整音量和试听。已有开关设置保持不变。配置中的空 `path` 表示使用内置语音，
“恢复默认音频”清除自定义路径；关闭播报请使用该项开关。已有自定义路径、音量、时间与关闭状态保留。
修改提前时间时，应同时选用与该时间相符的录音。

`../defaults.py` 维护资源与播报项的对应关系。PyInstaller 收集插件内的数据文件；
`scripts/check_runtime_resources.py` 和 `scripts/package_release.py` 会拒绝缺少默认语音的构建。
