## Overview

This feature detects teammate down states and plays looping audio automatically.

## Initial setup

### 1. Calibrate the teammate status area.

ℹ️ **Note: This step is optional. The program automatically calculates the detection region from a 16:9 full-screen game image. Manually calibrate it only if the game is not full screen or the automatic region is incorrect.**

Set a controller or keyboard shortcut, then enter the training area or a three-player scene and press the shortcut to open the calibration screen.

![Set calibration shortcut](1.jpg)

Click the upper-right button to start selecting. Select the area containing the complete teammate portraits and health bars, or the area shown in the training menu, then press Enter or Save to confirm.

![Calibration screen](2.jpg)

Return to the main window. A green "Calibrated" status indicates success. Hover over the eye icon to preview the region.

### 2. Enable detection and audio.
