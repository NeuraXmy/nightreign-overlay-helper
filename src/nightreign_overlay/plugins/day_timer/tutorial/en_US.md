## Overview

By recognizing the DAY I / DAY II / DAY III icons that appear at the start of each day in the game, the overlay automatically runs the circle countdown. You can also control the timer with shortcuts.

## Initial setup

### 1. Select your NIGHTREIGN game language.

![Game language selection](1.jpg)

### 2. Calibrate the DAY I icon region.

It is recommended to set a controller or keyboard shortcut. Start a single-player game and press the shortcut when the DAY I icon is fully visible to open the calibration screen.

![Set calibration shortcut](2.jpg)

Click the button in the upper-right corner to start selecting (if the mouse cannot move, try clicking the left mouse button once). Select the region as tightly as possible around the DAY I icon, including the protruding serifs on both sides of the letters, then press Enter or the Save button to confirm.

![Calibration screen](3.jpg)

Return to the main window. A green "Calibrated" status indicates success. Hover over the eye icon to view the calibrated region.

### 3. Set manual shortcuts.

You can set shortcuts for manually controlling the timer, or start the timer directly from the main window.

![Shortcuts](4.jpg)

## Result

![Appearance](5.jpg)

The appearance of the main overlay can be adjusted in the general "Settings".

## Notes

At the start of each day, wait for the DAY X icon to appear completely before opening the inventory or map. Otherwise another screen may cover the DAY X icon and automatic timing will not start.

It is normal for the DAY III timer to continue after a game ends; this does not affect use.

For other recognition failures or inaccurate results, see the "FAQ" page.
