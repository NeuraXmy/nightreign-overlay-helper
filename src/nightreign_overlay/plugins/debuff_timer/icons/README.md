# 异常量表实景图标参考

这些参考从异常量表截图直接无损裁剪，原 43×43 框每边向内收缩 3 像素，最终为 37×37，去除不属于图标的外围边缘；不再使用地图信息页的异常图标。编号沿用地图状态 ID，仅用于整理模板，检测器不输出类型。

坐标相对于 `tests/data/debuff/` 中的检测区域截图，格式为 `(x, y, 宽, 高)`：

量表图标带有半透明背景。编号 0 保留普通场景、明亮火焰场景两份实景参考，以覆盖实际背景差异。共 8 张参考，每张按原图标外框 20、22、24、26、28 像素五种尺度缓存内部模板（实际模板边长为 17、19、21、22、24 像素），共 40 个灰度模板。优先匹配常见的 22 像素外框尺度，找到任意一组有效图标和量表后立即返回。量表位置根据裁剪前外框推算，避免内裁导致量表错位。整体匹配阈值为 0.80，内部细节阈值为 0.70，同时验证右侧水平量表。

新增参考时应补充无量表背景反例，并测试各量表行单独存在，避免其他图标命中掩盖某一类别漏检。

内部还验证高通细节：灰度模板减去 σ=2 的高斯平滑结果，内裁 2 像素后缓存；候选区域做相同处理，相关系数至少为 0.70。这样整体明暗轮廓相似、但没有异常符号纹理的背景不能仅凭灰度相关性通过。
