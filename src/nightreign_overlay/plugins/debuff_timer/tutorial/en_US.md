## Overview

Detects status buildup meters and displays the attack power stacks from the King of Wastes relic effect and the countdown to the next check.

## Initial setup

### 1. Calibrate the meter area

ℹ️ This step is **optional**. The program automatically calculates the detection region from a 16:9 full-screen game image.

If the automatic region does not work correctly, the game is not full screen, or you want to detect a window other than the game, see the [Calibration Tutorial](app://tutorial/region-calibration).

:::collapse Manual calibration steps

It is recommended to set a controller or keyboard shortcut, then enter a scene where a status buildup meter appears and press the shortcut to open the calibration screen.

![Set calibration shortcut](1.jpg)

Click the upper-right button to start selecting (if the mouse cannot move, try clicking the left mouse button once). Select the **area where status buildup meters may appear**, then press Enter or Save to confirm.

![Calibration screen](2.jpg)

Return to the main window. A green "Calibrated" status indicates success; hover over the eye icon to view the calibrated region.

:::
