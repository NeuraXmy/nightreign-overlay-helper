# 功能介绍

启用后显示 Steam 联机队友的昵称、Ping 和稳定度。默认还显示黑夜君临累计游戏时长，不需要 API Key；可以关闭「显示游戏时长」来停止查询并隐藏该列。

时长来自公开 Steam 主页。隐私限制、主页未展示本游戏或请求失败时会显示「时长不可用」，不会当成零小时。

点击队友名字可在 Steam 内置浏览器打开对应主页。拖动名字不会跳转，右键菜单仍可使用。选择「穿透」鼠标交互时不能点击窗口，请先改为可交互模式。

赛后点赞在左侧独立的「赛后点赞」页面设置，并使用单独的限时窗口。

## 自动屏蔽与恢复

设置页的「自动屏蔽非好友队友」默认关闭。开启后，有效延迟出现即可尝试，无需等待 DAY1；好友、未知关系和原有屏蔽均跳过。两名队友分别处理，准备失败会重试，确认离队或关闭功能后恢复。

短暂名单丢失不会立即解除。闪退或断网后保留恢复记录，独立组件继续重试；重新打开助手时，即使开关关闭也会接续恢复。请保持原 Steam 账号在线，不要删除待恢复记录。网络不可用时无法保证即时解除，状态会显示在开关下方。

赛后点赞需等该队友解除完成才能发送，点击名字打开主页不受影响。不要同时运行旧版和新版助手。

## 初次设置

保证以管理员模式打开悬浮助手，之后打开游戏即可使用。

可以在该功能的设置中单独调整悬浮窗的外观。
