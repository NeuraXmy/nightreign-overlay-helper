# 联机状态

启用后显示 Steam 联机队友的昵称、Ping 和稳定度。未连接游戏或 Steam 时显示当前状态，游戏运行但尚未找到有效会话时显示“等待队友 / 等待 Steam 同步”。本功能独立运行，不依赖截图或标定。

## Windows

需要 Steam 已登录、游戏正在运行以及已构建的 `NightreignP2PHelper.exe`。开发环境执行仓库中的 `scripts/build_p2p_helper.ps1`。发布包需要保留 `bin` 中的 EXE 和 `amd64` 支持 DLL，详情见仓库 README。

新 Steam 接口直接返回延迟和本地连接质量；旧接口通过管理员权限下的 ETW 网络事件推断 STUN 往返时间。没有管理员权限时仍查询队友，新接口指标仍可用，旧接口指标显示 `--`。可在设置的运行状态中查看 SteamAPI、ETW 和辅助进程状态。

旧接口的稳定度使用最近最多 10 个有效 RTT 样本的标准差计算，至少 3 个样本才显示。它衡量延迟抖动，不是丢包率；新接口显示 Steam 自身提供的本地连接质量，两者含义不同。

Ping 默认小于 80ms 为绿、80～149ms 为黄、150ms 起为红，可在设置中修改。缺失延迟显示灰色 `-- ms`，缺失稳定度显示 `--`。悬停玩家名称可查看 SteamID、接口和延迟来源。

## 悬浮窗调整

悬浮窗没有面板背景和标题，文字带有与主悬浮窗相同的阴影。正常运行时直接显示玩家列表；未知指标仍显示 `--`，接口和来源可通过昵称提示查看。

复用主悬浮窗的通用设置：大小、透明度、普通/锁定/鼠标穿透，以及位置重置。普通模式可直接拖动，锁定模式保持位置，鼠标穿透模式允许操作下方游戏。大小默认 100%，透明度默认 75%，默认位于主屏右上方；重置后立即保存位置，无需再拖动。窗口以右上角为锚点，大小变化时锚点位置保持不变。右键打开主界面或退出程序（穿透模式下请从主界面调整）。

窗口遵循通用设置中的前台显示规则，包括主界面、菜单和标定选区的临时显示例外；普通窗口模式与主悬浮窗一致，不受游戏前台显示门控。游戏切到后台只隐藏透明窗口，不暂停 Steam / ETW 网络查询；全局“显示和检测”选项暂停的是截图检测，网络查询仍沿用旧版独立运行的行为。

## macOS 开发模拟

macOS 自动启动独立 Python 模拟程序，沿用同样的 JSONL 通信和一秒更新间隔，无需 Steam、管理员权限或 .NET。状态区域明确标明模拟数据。

约 32 秒一轮，依次演示：等待队友、旧接口指标为空、两名队友、绿/黄/红延迟、新队友加入与行顺序保持、队友清空。插件关闭后模拟进程退出，重新启用从头演示。这仅验证主程序的设置、显示和生命周期，不能验证 Windows 的 Steam/ETW 测量。
