# 聯機狀態

啟用後會顯示 Steam 聯機隊友的暱稱、Ping 和穩定度。

## 自動封鎖與恢復

設定中的「自動封鎖非好友隊友」預設關閉。啟用後取得有效延遲即可嘗試，無需等待 DAY1；好友、未知關係及原有封鎖均跳過。兩名隊友獨立處理，準備失敗會重試，確認離隊、關閉功能或退出後恢復。

短暫名單中斷不會立即解除。斷網或程式崩潰後保留恢復紀錄，獨立元件繼續重試；下次啟動時，即使開關關閉也會接續。請保持原 Steam 帳號在線，不要刪除待恢復紀錄；離線時無法保證立即解除。賽後留言會等待解除確認，名字仍可開啟個人檔案。不要同時執行新舊助手。

## 初次設定

請以管理員身分開啟懸浮助手，之後開啟遊戲即可使用。

可以在此功能的設定中單獨調整懸浮窗的外觀。
