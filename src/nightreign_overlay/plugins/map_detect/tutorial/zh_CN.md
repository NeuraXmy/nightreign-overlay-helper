# 地图信息

该功能通过解包数据展示详细地图剧透。请确保不会影响你和队友的游戏体验。地图解包数据来自 Fuwish@bilibili；部分地图数据可能有错误。

1. 在设置页点击地图区域的「标定」，或先绑定标定快捷键后在游戏中按键。

   ![区域快捷键](1.jpg)

2. 在有地图的游戏画面中框选地图，选区边缘必须和地图边框完全贴合。保存时按旧版取选区左上角、宽高较小者作为边长，保持正方形。

   ![地图选区](2.jpg)

3. 返回设置确认显示「已标定」。悬停眼睛图标可预览区域。

   ![确认区域](3.jpg)

地图必须缩放到最小、完整显示才可识别。Day1 计时开始（自动或手动）会准备一次识别；启动、重新标定和「识别地图」操作也会准备识别。实际旧版代码还每隔 2100 秒准备重新识别，新版保留这一行为。准备时先清除旧信息，再等下一帧；地形匹配成功后才匹配地图，避免地图刚打开仍半透明时识别。

除标定外的快捷键统一放在设置页的「快捷键」分组中，可绑定重新识别、显隐切换、候选切换、水晶布局切换及手动筛选。需要鼠标操作时，可使用地图下方的操控栏。

识别结果叠加到原地图上，暂不跟随地图缩放。完整地图打开／关闭时自动渐显／渐隐，也可手动显示／隐藏。可绑定「下一个／上一个识别结果」切换候选；默认返回 3 个，范围 1–10。大空洞识别后同时显示水晶点位，可在「所有」和四种布局间循环，图例区分地面、地下和额外水晶。

保留信息包括 Day1／Day2 及额外 Boss、野外与主城 Boss、主城及下水道类型、建筑与属性、法师塔、马车、特殊事件、血瓶、神授塔楼层 Boss、宝藏、癫火塔与腐败庇佑。游戏内容名称和图内图例沿用旧版中文数据。

HDR 归一化使用通用设置中的 HDR 图像处理开关。地图识别使用旧版 LAB／CLAHE，其他功能各按自己的处理方式读取共享帧。

设置页的「高级检测选项」可调整自动匹配间隔（默认 2100 秒）、完整地图误差阈值（20）、特殊地形误差阈值（50）、POI 子图标阈值（0.06），以及已匹配／未匹配夜王时的 POI 采样比例（均为 1.0）。误差阈值越大，判断越宽松；子图标匹配分数高于阈值时视为没有子图标。降低采样比例可减少耗时，但可能降低识别稳定性；采样仍遵循旧版至少 8 点的规则。修改后的参数用于后续检测；已有候选结果需点击「识别地图」重新生成。

这些参数仍保存在用户 settings.yaml 的 `plugins.map_detect` 中，默认值与旧版 config.yaml 相同。`full_map_hough_circle_thres`（霍夫圆阈值列表）、`fixed_map_overlay_draw_size`（固定绘制尺寸）和 `map_overlay_draw_size_ratio`（绘制比例）继续通过配置文件调整。

标定保存时输出 `map_region_screenshot.jpg`；识别仍输出 `map.jpg`、`map_poi_result.jpg` 和 `map_overlay_result_<序号>.jpg`，便于反馈排查；新版输出到自己的用户数据目录。

「上一张／下一张地图」「上一个／下一个水晶布局」和「重新识别」快捷键仅在地图信息悬浮窗显示时响应；隐藏时按键不会修改候选、布局或识别状态。自动识别仍按 Day1、标定及匹配间隔等条件触发。
