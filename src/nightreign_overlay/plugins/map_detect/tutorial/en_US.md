## Overview

By recognizing special terrain, Nightlord portraits, and site types on the map, this feature filters map seeds and displays detailed site information for the matching seed. It supports all maps, including DLC maps, as well as hidden Nightlords and events where map details are hidden (manual filtering may be required).

## Notice

This feature can **significantly affect normal gameplay**. It is not recommended for public matchmaking or for use without good communication with your teammates.

## Initial setup

### 1. Calibrate the map region.

This step is optional. The program automatically calculates the detection region from a 16:9 full-screen game image. Manually calibrate it only if the game is not full screen or the automatic region is incorrect.

It is recommended to set a controller or keyboard shortcut. Then enter the Roundtable Hold or any scene where the map can be opened, and press the shortcut to open the calibration screen.

![Set calibration shortcut](1.jpg)

Click the button in the upper-right corner to start selecting (if the mouse cannot move, try clicking the left mouse button once). Select the **square map area**, then press Enter or the Save button to confirm.

![Calibration screen](2.jpg)

Return to the main window. A green "Calibrated" status indicates success. Hover over the eye icon to view the calibrated region.

### 2. Learn manual filtering.

If recognition fails, or if an event hides detailed map information at night, use the buttons at the bottom of the interface to enter manual filtering mode.

First select the special terrain and Nightlord, then set the site positions on the map. "Auto recognize" is only applicable to events with missing map information, when site icons become visible after a site is conquered.

The number of current candidate maps is shown in the lower-right corner. Filtering ends automatically when the number falls below a certain threshold.

![Manual filtering](3.jpg)

### 3. Trigger recognition

After setup, recognition starts automatically when the in-game minimap is fully open.

How do you recognize again in a new run?

1. If the circle timer is enabled, recognition restarts automatically when DAY I begins.
2. Press the "Recognize again" button or use its shortcut.
3. After a successful recognition, the "Rematch interval" in "Advanced" automatically resets recognition after the configured number of seconds (approximately one run).

## Result

![Appearance](4.jpg)

Use the buttons in the lower-left corner or shortcuts to switch between map candidates. If the result is incorrect, check whether another candidate is correct.

For the Great Hollow, you can also switch between several crystal layouts.

## Notes

Do not repeatedly open and close the map while recognition is running.

Recognition only works when the map is minimized; zoomed minimaps are not supported.

For other recognition failures or inaccurate results, see the "FAQ" page.
