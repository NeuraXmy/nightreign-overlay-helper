# 地图信息本地化资源

UI 和绘制文字沿用插件的 `<语言代码>.yaml`，中文基础资源为 `zh_CN.yaml`。
例如 `overlay.matching` 是识别中提示，`overlay.legend` 是水晶图例，
`overlay.duration` 是时间单位，`drawing` 是直接绘制到地图图片中的文字。
缺少语言文件或词条时使用中文。插件 UI 的测试只要求中文词条完整，其他语言不检查缺项；翻译时请保留词条中的格式占位符。

名字表放在 `<语言代码>-names.csv`，例如 `zh_CN-names.csv`。
格式保持 `id,name`，UTF-8 编码（也支持 BOM），ID 必须保留为游戏数据中的整数 ID。
运行时按 ID 覆盖中文表，未列出或名称为空的条目仍使用中文。发布资源的测试要求更严格：每个正式语言的名称表必须覆盖中文表的全部 ID，名称非空且 ID 不重复；检查直接读取 CSV，避免中文回退掩盖缺项。
已有中文表中最后的多余空列沿用原始资源，不影响读取。
若某个 ID 在所有表中均不存在，绘制仍沿用原逻辑显示数字 ID。
地图模板、建筑表、位置表及匹配数据继续保留在 `data`，不随语言变化。

插件使用应用启动时选定的语言，与现有设置页面和教程的语言机制一致。
新增正式语言还需按主程序约定在核心 `resources/i18n` 中注册该语言；
仅增加名字表不会新增全局语言选择项。地图名称提供简体中文、英文、日文及繁体中文；缺少的界面词条回退中文。

英文地图地标文字默认按原宽度的 50% 横向绘制，文字高度及标注位置保持不变。
在地图功能设置的「英文地标文字宽度」中可调整为 10%–100%，100% 恢复原宽度，下次识别生效。
该选项仅在应用语言为 en_US 时作用于地图地标，顶部地图说明及其他语言保持原宽度。
