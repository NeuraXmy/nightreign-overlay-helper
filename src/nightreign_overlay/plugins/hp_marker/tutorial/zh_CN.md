# 血量阈值标记

在血条上方显示 40%（血量偏低触发词条）、85%（非满血相关负面词条）和 100%（满血）三条参考标记。该功能检测完整血条的长度，不是当前血量百分比，也不检测雨中血条颜色。

1. 点击设置页「血条区域」的「标定」，也可先绑定标定快捷键后在游戏中按键。

   ![设置快捷键](1.jpg)

2. 在任意有血条的游戏画面中框选血条区域。

   ![框选血条](2.jpg)

3. **高度与血条完全相同，左边缘紧贴血条，框选宽度不限。** 检测会从左侧向右扩展，默认宽度为选区高度的 125 倍。

   ![选区要求](3.jpg)

4. 回到设置页确认「已标定」。悬停眼睛图标可预览选区，之后血条上方自动显示三条标记。

   ![标定成功](4.jpg)

低／高血量标记可分别调整，默认 0.40／0.85，满血线固定为 100%。线宽、线高和颜色默认沿用旧版的 3×7 物理像素白线。位置自动跟随检测区域和血条长度，不能拖动，也不保存为普通窗口位置。窗口接入全局前台显示规则，始终鼠标穿透。

高级选项提供旧版亮度峰检测起点、最低亮度、亮度提升阈值、比较区间、标准缩放高度、截取宽高比和历史样本数。检测保持原始截图，不做 HDR 转换。参数修改影响后续检测，历史样本和平滑过程仍沿用旧版。

**旧版行为说明：**「检测失败时保持上次结果」的设置值虽然会保存，但旧版检测器未使用该参数，更新器也只在获得有效长度时更新窗口。因此不论开关状态如何，失败时都保留已有标记；稳定的历史检测值也可能继续输出。新版忠实保留此行为，未改成“失败就隐藏”。首次启动且没有有效结果时不显示；清除标定或停用插件后隐藏。

标定保存时仍输出 `hpbar_region_screenshot.jpg` 到新版用户数据目录，便于排查。
