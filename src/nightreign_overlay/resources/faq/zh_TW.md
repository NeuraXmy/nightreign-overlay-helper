## 遊戲全螢幕時懸浮窗沒有顯示

遊戲需要以「視窗化」或「無邊框視窗化」模式執行，不支援「全螢幕」模式。

## 懸浮窗一直顯示半透明背景

主介面尚未關閉時，懸浮窗會顯示半透明背景，方便拖曳位置。

## 關閉主介面後無法完全退出程式

在懸浮窗或系統匣圖示上按右鍵，選擇「結束程式」。

## 辨識錯誤或不準確，應該檢查什麼

請檢查以下內容：

1. 確認功能已開啟，並按照教學完成完整的初步設定。
2. 確認標定區域正確。每個功能都有各自的標定區域要求。
3. 一般「設定」中的「偵測間隔」可能設定得太大，導致偵測反應不靈敏，建議使用預設的 250ms。
4. 確認需要偵測的區域（地圖或血條）沒有被本助手或其他應用程式的懸浮窗遮擋。
5. 如果遊戲開啟 HDR（顯示設定 → 高動態範圍），或其他設定改變了遊戲畫面的色彩，辨識可能會變得不準。可以嘗試在一般「設定」中開啟「啟用 HDR 圖像處理」，或許能改善問題，但修改設定後仍無法保證解決，建議關閉 HDR 使用。
6. 如果螢幕數量、螢幕解析度或遊戲視窗大小發生變化，請重新進行標定。

## 開啟後系統或遊戲卡頓

請檢查以下內容：

1. 一般「設定」中的「偵測間隔」可能設定得太小，導致擷取畫面並進行辨識的頻率過高，建議使用預設的 250ms。
2. 地圖資訊功能中的「辨識結果回傳數量」設定過大，可能會消耗較多效能。
3. 懸浮窗可能影響系統大小核排程，可以使用 Process Lasso 等工具設定本助手只使用效率核心執行。
4. 程式本身的辨識功能也需要消耗一定效能。

## 和 Lossless Scaling 等補幀軟體一起使用時遊戲卡頓

懸浮窗很難與補幀軟體相容，目前無法解決此問題。部分功能（例如縮圈計時）的懸浮窗可以移到與遊戲不同的另一個螢幕，以避免這個問題。

## 更新版本時是否需要保留舊檔案，設定會不會遺失

設定檔案存放在獨立的使用者資料目錄中，與程式本體分開，因此可以放心刪除舊版程式檔案。

## 使用本助手是否會觸發反作弊偵測

請參閱「關於」頁面的「安全性聲明」。

## 上述方法都無法解決問題

這是非營利專案，若造成困擾敬請見諒。

請使用「關於」頁面的「問題回報」。建議在問題發生後立即回報，程式會自動將近期日誌和辨識結果打包成 ZIP 壓縮檔，請透過電子郵件寄給作者。

請不要只在 GitHub Issues 或 Bilibili 留言區以文字描述問題。
